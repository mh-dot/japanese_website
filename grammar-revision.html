N5 গ্রামার রিভিশন

৯৭টি রুল · বাক্যের গঠন · ২টি করে উদাহরণ · ছোট নোট

লেসন ১পরিচয় · は・です・か・も・の・さん

A は B です“A হলো B” · は, です

A は B です

は বাক্যের বিষয় বোঝায় (“আমি-টা”), আর です শেষে বসে বাক্যকে ভদ্র করে; বাংলার “হয়” এখানে です।

  • 私わたし は 学生がくせい です。আমি ছাত্র।
  • マイク さん は アメリカ人じん です。মাইক আমেরিকান।

💡 は লেখা “হা”, পড়া “ওয়া”।

じゃ ありません“A হলো B নয়” · じゃ ありません

A は B じゃ ありません

です এর না-বোধক রূপ じゃ ありません (লেখায় ではありません), বিশেষ্যের পরে বসে।

  • 私わたし は 先生せんせい じゃ ありません。আমি শিক্ষক নই।
  • ミラー さん は 医者いしゃ じゃ ありません。মিলার ডাক্তার নন।

💡 じゃ ありません = “নয়”।

か・はい・いいえপ্রশ্ন ও উত্তর · か

A は B です か

বাক্যের শেষে か বসালেই প্রশ্ন হয় (? লাগে না)।

  • あなた は 学生がくせい です か。আপনি কি ছাত্র?
  • はい、 学生がくせい です。হ্যাঁ, ছাত্র।

💡 か প্রশ্নচিহ্নের কাজ করে।

も“-ও” · も

A も B です

আগের কথার সাথে মিল থাকলে は এর জায়গায় も বসে।

  • 私わたし も 学生がくせい です。আমিও ছাত্র।
  • ミラー さん も 先生せんせい じゃ ありません。মিলারও শিক্ষক নন।

💡 は ও も একসাথে বসে না।

の“-র / -এর” · の

A の B

দুই বিশেষ্য জুড়ে মালিকানা বা সম্পর্ক বোঝায়: মালিক আগে, জিনিস পরে (আমার বই = 私の本)।

  • 私わたし の 本ほん です。আমার বই।
  • ミラー さん は IMC の 社員しゃいん です。মিলার IMC এর কর্মী।

💡 の = “-র”; মালিক আগে বসে।

さん・人・歳সম্বোধন ও পরিচয় · さん/人/歳

名前 さん / 国くに 人じん / ～歳さい

さん অন্যের নামের পরে সম্মান বোঝায় (নিজের নামে নয়)।

  • 山田やまだ さん は 日本人にほんじん です。ইয়ামাদা জাপানি।
  • 私わたし は バングラデシュ人じん です。আমি বাংলাদেশি।

💡 নিজের নামের পরে さん নয়।

লেসন ২জিনিস দেখানো · これ・この・そう

これ・それ・あれ“এটা・ওটা・ঐটা” · これ/それ/あれ

これ/それ/あれ は N です

দূরত্বে তিন ভাগ: これ = বক্তার কাছে, それ = শ্রোতার কাছে, あれ = দুজনেরই দূরে।

  • これ は 本ほん です。এটা বই।
  • それ は 何なん です か。ওটা কী?

💡 それ = শ্রোতার দিকের জিনিস।

この・その・あの + N“এই・ওই・ঐ + বিশেষ্য” · この/その/あの

この/その/あの N は ～ です

これ-দল একা বসে, কিন্তু この-দলের পরে সবসময় একটি বিশেষ্য আসে (この本)।

  • この 本ほん は 私わたし の です。এই বইটা আমার।
  • その かばん は だれ の です か。ওই ব্যাগ কার?

💡 この এর পরে বিশেষ্য ছাড়া বসে না।

そう です・そう じゃ ありません“তাই / তা নয়” · そう です

そう です / そう じゃ ありません / そう です か

হ্যাঁ-না প্রশ্নের উত্তরে そう です (তাই) ও そう じゃ ありません (তা নয়) বলা যায়।

  • それ は 時計とけい です か。ওটা কি ঘড়ি?
  • はい、 そう です。হ্যাঁ, তাই।

💡 そう です か = শুনে বুঝলাম।

A です か、 B です か“A নাকি B?” · か ～ か

A です か、 B です か

দুটি বিকল্প থেকে একটি বাছাই করাতে প্রতিটির শেষে か বসে।

  • これ は 本ほん です か、 ノート です か。এটা বই নাকি খাতা?
  • ノート です。খাতা।

💡 উত্তরে はい/いいえ লাগে না।

の・だれの“কার / কীসের” · の, だれの

N1 の N2 / だれ の N / 何 の N

の দিয়ে বিষয় বা ধরন বোঝানো যায় (日本語の本 = জাপানি ভাষার বই)।

  • これ は 日本語にほんご の 本ほん です。এটা জাপানি ভাষার বই।
  • それ は だれ の かさ です か。ওটা কার ছাতা?

💡 だれ の = “কার”।

লেসন ৩স্থান ও দাম · ここ・こちら・いくら

ここ・そこ・あそこ・どこ“এখানে・ওখানে・ঐখানে・কোথায়” · ここ/そこ/あそこ/どこ

N は ここ/そこ/あそこ です / N は どこ です か

ここ = বক্তার কাছে, そこ = শ্রোতার কাছে, あそこ = দুজনেরই দূরে, どこ = কোথায়।

  • ここ は 教室きょうしつ です。এটা ক্লাসরুম।
  • トイレ は どこ です か。টয়লেট কোথায়?

💡 প্যাটার্ন: জিনিস は স্থান です।

こちら・そちら・あちら・どちら“এদিক…” (ভদ্র রূপ) · こちら 系

こちら は N さん です / お 国くに は どちら です か

ここ・そこ・あそこ・どこ এর ভদ্র রূপ।

  • こちら は 山田やまだ さん です。ইনি ইয়ামাদা-সান।
  • お 国くに は どちら です か。আপনার দেশ কোথায়?

💡 অতিথি ও অফিসে こちら ব্যবহার করুন।

の (কোথাকার)“…র তৈরি / …কার” · の

N1 の N2 / どこ の N

の দিয়ে কোন দেশ বা কোম্পানির জিনিস তা বলা যায়।

  • これ は 日本にほん の 車くるま です。এটা জাপানের গাড়ি।
  • その かばん は どこ の です か。ওই ব্যাগ কোথাকার?

💡 どこ の = কোথাকার।

いくら・円“কত দাম” · いくら, 円

N は いくら です か / ～円えん です

দাম জিজ্ঞেসে いくら।

  • これ は いくら です か。এটা কত?
  • 三百さんびゃく 円えん です。৩০০ ইয়েন।

💡 ひゃく ও せん এর উচ্চারণ বদলায়।

～階“…তলা” · ～階

N は ～階かい です

তলা বলতে সংখ্যা + 階: いっかい (১), にかい (২), さんがい (৩), よんかい (৪), ごかい (৫), ろっかい (৬), はっかい (৮), じゅっかい (১০)।

  • トイレ は 三階さんがい です。টয়লেট তিন তলায়।
  • ここ は 何階なんがい です か。এটা কত তলা?

💡 ১, ৩, ৬, ৮, ১০ এর উচ্চারণ বিশেষ।

লেসন ৪সময় ও দৈনন্দিন কাজ · ます・に・から・まで

今 何時 ですか“এখন কয়টা” · 時・分

今いま ～時じ ～分ふん です

সংখ্যা + 時 (ঘণ্টা) + 分 (মিনিট); আধা ঘণ্টা = 半[はん]।

  • 今いま 何時なんじ です か。এখন কয়টা বাজে?
  • 今いま 九時くじ 半はん です。এখন সাড়ে নয়টা।

💡 ৪ = よじ, ৭ = しちじ, ৯ = くじ নিয়মের বাইরে।

V ます・ません・ましたক্রিয়ার ভদ্র চার রূপ · ます 系

V ます / V ません / V ました / V ませんでした

ক্রিয়া বাক্যের শেষে বসে।

  • 毎日まいにち 働はたらきます。রোজ কাজ করি।
  • 昨日きのう 勉強べんきょう しました。গতকাল পড়েছি।

💡 ます দিয়ে শেষ = ভদ্র রূপ।

に (সময়)“…সময়ে” · に

時間 に V

নির্দিষ্ট ঘণ্টা বা বারের পরে に বসে।

  • 毎朝まいあさ 六時ろくじ に 起おきます。রোজ সকালে ছয়টায় উঠি।
  • 十一時じゅういちじ に 寝ねます。এগারোটায় ঘুমাই।

💡 নির্দিষ্ট সময় → に, ‘আজ/রোজ’ → না।

から・まで“থেকে・পর্যন্ত” · から/まで

A から B まで V

から = শুরু, まで = শেষ; সময় ও স্থান দুটোতেই চলে।

  • 九時くじ から 五時ごじ まで 働はたらきます。নয়টা থেকে পাঁচটা কাজ করি।
  • 銀行ぎんこう は 九時くじ から です。ব্যাংক নয়টা থেকে।

💡 から ছাড়া একা ব্যবহার করলে “…থেকে” মাত্র।

と・ね“এবং” ও “…তাই না?” · と, ね

N1 と N2 / 文 ね

と দুই বা বেশি বিশেষ্য জোড়ে (শুধু বিশেষ্য)।

  • 山田やまだ さん と 私わたし は 学生がくせい です。ইয়ামাদা ও আমি ছাত্র।
  • 今いま 九時くじ です ね。এখন নয়টা, তাই না?

💡 と শুধু বিশেষ্য জোড়ে, ক্রিয়া নয়।

লেসন ৫যাওয়া-আসা ও তারিখ · へ・で・と・いつ

へ + 行く・来る・帰る“…-তে যাই/আসি/ফিরি” · へ

場所 へ 行いきます

গন্তব্য বোঝায় へ (লেখা “হে”, পড়া “এ”)।

  • 学校がっこう へ 行いきます。স্কুলে যাই।
  • 日本にほん へ 来きました。জাপানে এসেছি।

💡 は এর মতো へ এরও লেখা আর পড়া আলাদা।

で (যানবাহন)“…দিয়ে / …-তে করে” · で

乗り物 で 行いきます / 何なん で

যানবাহনের পরে で বসে (মাধ্যম)।

  • 電車でんしゃ で 会社かいしゃ へ 行いきます。ট্রেনে অফিস যাই।
  • 何なん で 来きました か。কিসে করে এসেছেন?

💡 で = উপায় বা মাধ্যম।

と ও ひとり で“…র সাথে” · と

人 と V / だれ と / ひとり で

と সঙ্গীর পরে বসে; প্রশ্নে だれ と (কার সাথে)।

  • 友達ともだち と 学校がっこう へ 行いきます。বন্ধুর সাথে স্কুলে যাই।
  • だれ と 来きました か。কার সাথে এসেছেন?

💡 ひとり で = একা।

いつ・তারিখ“কখন” · いつ, 月・日

いつ V / 何月なんがつ 何日なんにち

いつ = কখন; এর পরে に লাগে না।

  • いつ 日本にほん へ 来きました か。কখন জাপানে এসেছেন?
  • 三月さんがつ 二十五日にじゅうごにち に 来きました。২৫ মার্চে এসেছি।

💡 ১–১০ তারিখ আলাদা শব্দ।

よ“…তো” (জানানো) · よ

文 よ

বাক্যের শেষে よ শ্রোতার জানা নেই এমন কথা জানায় বা জোর দেয়।

  • この 電車でんしゃ は 学校がっこう へ 行いきます よ。এই ট্রেন স্কুলে যায় তো।
  • 明日あした 来きます よ。কাল আসব (জানিয়ে রাখলাম)।

💡 ね = “তাই না?”, よ = “জেনে রাখুন”।

লেসন ৬খাওয়া-কেনা ও আমন্ত্রণ · を・で・ませんか・ましょう

をকর্মপদ চিহ্ন · を

N を V ます

কাজের কর্ম (কী খাই, কী দেখি) বোঝাতে を বসে: 食[た]べます খাই, 飲[の]みます পান করি, 買[か]います কিনি, 見[み]ます দেখি, 読[よ]みます পড়ি।

  • ご飯はん を 食たべます。ভাত খাই।
  • 水みず を 飲のみます。পানি পান করি।

💡 を লেখা “wo”, পড়া “ও”।

で (কাজের স্থান)“…-তে (কাজ ঘটে)” · で

場所 で N を V

কাজ যেখানে ঘটছে সেই স্থানের পরে で বসে।

  • 図書館としょかん で 本ほん を 読よみます。লাইব্রেরিতে বই পড়ি।
  • レストラン で ご飯はん を 食たべます。রেস্তোরাঁয় ভাত খাই।

💡 で = কাজ কোথায় হচ্ছে।

V ませんかআমন্ত্রণ · ませんか

いっしょ に V ませんか

“করবেন কি?” — অন্যকে ভদ্রভাবে ডাকতে।

  • いっしょ に 食たべません か。একসাথে খাবেন কি?
  • いっしょ に 映画えいが を 見みません か。একসাথে সিনেমা দেখবেন কি?

💡 ませんか = আমন্ত্রণ, প্রশ্ন নয়।

V ましょうপ্রস্তাব · ましょう

V ましょう

“চলুন করি” — নিজে সহ একসাথে করার প্রস্তাব বা আমন্ত্রণ গ্রহণ।

  • ちょっと 休やすみましょう。একটু বিশ্রাম নিই।
  • いっしょ に 行いきましょう。চলুন একসাথে যাই।

💡 ましょう = চলুন…

লেসন ৭উপায় ও দেওয়া-নেওয়া · で・あげます・もらいます・もう

で (উপায়・ভাষা)“…দিয়ে / …ভাষায়” · で

N で V

উপকরণ বা ভাষার পরে で বসে (কী দিয়ে/কোন ভাষায়)।

  • はし で 食たべます。চপস্টিক দিয়ে খাই।
  • ペン で 書かきます。কলম দিয়ে লিখি।

💡 で = উপায়, উপকরণ বা ভাষা।

～語 で 何ですか“…ভাষায় কী” · ～語[ご] で 何[なん]

N は ～語ご で 何なん です か

কোনো শব্দ অন্য ভাষায় কী, তা জিজ্ঞেস করার ছাঁচ।

  • ありがとう は 英語えいご で 何なん です か。ありがとう ইংরেজিতে কী?
  • これ は 日本語にほんご で 何なん です か。এটা জাপানিতে কী?

💡 ছাঁচ: N は ～語 で 何 ですか।

あげます (দেওয়া)“দিই” · あげます 系

人 に N を あげます

কাউকে কিছু দিতে: あげます দিই, 貸[か]します ধার দিই, 教[おし]えます শেখাই/জানাই।

  • 私わたし は 友達ともだち に 花はな を あげます。আমি বন্ধুকে ফুল দিই।
  • 山田やまだ さん に ペン を 貸かします。ইয়ামাদাকে কলম ধার দিই।

💡 যাকে দিই → に, কী দিই → を।

もらいます (পাওয়া)“পাই” · もらいます 系

人 に N を もらいます

কারো কাছ থেকে পেতে: もらいます পাই, 借[か]ります ধার নিই, 習[なら]います শিখি।

  • 友達ともだち に 本ほん を もらいました。বন্ধুর কাছ থেকে বই পেয়েছি।
  • 山田やまだ さん に 本ほん を 借かります。ইয়ামাদার কাছ থেকে বই ধার নিই।

💡 に = কার কাছ থেকে।

もう・まだ“ইতিমধ্যে / এখনো না” · もう, まだ

もう V ました か / はい、 もう V ました / いいえ、 まだ です

もう ～ました = ইতিমধ্যে করেছি।

  • もう ご飯はん を 食たべました か。ভাত খেয়েছেন কি ইতিমধ্যে?
  • はい、 もう 食たべました。হ্যাঁ, খেয়েছি।

💡 না-উত্তরে まだ です।

লেসন ৮বিশেষণ · い形容詞・な形容詞

な-বিশেষণবিশেষণ (১) · な形容詞

N は な-adj です

きれい, にぎやか, 親切[しんせつ], 有名[ゆうめい] ইত্যাদি な-বিশেষণ; বাক্যের শেষে です বসে।

  • この 町まち は きれい です。এই শহর পরিষ্কার।
  • 東京とうきょう は にぎやか です。টোকিও প্রাণবন্ত।

💡 な-বিশেষণ = বিশেষ্যের মতো です যোগ।

い-বিশেষণবিশেষণ (২) · い形容詞

N は い-adj です

শেষে い থাকে: 高[たか]い, おいしい, おもしろい, 広[ひろ]い।

  • この 本ほん は おもしろい です。এই বই মজার।
  • あの 山やま は 高たかい です。ঐ পাহাড় উঁচু।

💡 い দিয়ে শেষ = い-বিশেষণ।

না-বোধক“নয়” · じゃ ありません / くない

な-adj じゃ ありません / い-adj ～くない です

な-বিশেষণ: じゃ ありません।

  • この 町まち は きれい じゃ ありません。এই শহর পরিষ্কার নয়।
  • この 本ほん は おもしろく ない です。এই বই মজার নয়।

💡 い → くない; いい → よくない।

বিশেষ্যের আগে বিশেষণ“সুন্দর শহর” · な + N / い + N

な-adj な N / い-adj N

な-বিশেষণ ও বিশেষ্যের মাঝে な বসে (きれいな 町)।

  • きれい な 町まち です。সুন্দর শহর।
  • 高たかい 山やま です。উঁচু পাহাড়।

💡 な-adj এর পরে な, い-adj এ কিছু না।

とても・あまり“খুব / তেমন না” · とても, あまり

とても + adj / あまり + না-বোধক

とても = খুব (হ্যাঁ-বোধকে)।

  • この 本ほん は とても おもしろい です。এই বই খুব মজার।
  • この 町まち は あまり にぎやか じゃ ありません。এই শহর তেমন প্রাণবন্ত নয়।

💡 あまり এর পরে না-বোধক।

どう・どんな“কেমন / কী রকম” · どう, どんな

N は どう です か / どんな N です か

どう = কেমন (মতামত জিজ্ঞেস)।

  • 日本にほん は どう です か。জাপান কেমন?
  • ミラー さん は どんな 人ひと です か。মিলার কেমন মানুষ?

💡 どんな এর পরে বিশেষ্য।

が・そして“কিন্তু / আর” · が, そして

S1 が、 S2 / S1。 そして、 S2

が = “কিন্তু” (বাক্যের মাঝে, ব্যতিক্রম বোঝায়)।

  • 日本にほん の 食たべ物もの は おいしい です が、 高たかい です。জাপানি খাবার সুস্বাদু কিন্তু দামি।
  • この 町まち は きれい です。 そして、 しずか です。এই শহর সুন্দর। আর শান্ত।

💡 が এখানে “কিন্তু”।

লেসন ৯পছন্দ ও কারণ · が・から・どうして

N が 好すき/きらい です

পছন্দ-অপছন্দের বিষয়ের পরে を নয়, が বসে।

  • 私わたし は 犬いぬ が きらい です。আমি কুকুর অপছন্দ করি।

💡 এখানে を নয়, が বসে।

N が 上手じょうず/下手へた です

দক্ষতার বিষয়ের পরে が বসে।

  • 私わたし は 歌うた が 下手へた です。আমি গানে কাঁচা।

💡 নিজেকে 上手 বলা অভদ্রতা।

が + あります・わかります“আছে / বুঝি” · が あります/わかります

N が あります / N が わかります

মালিকানা, সময়, টাকা ইত্যাদি থাকা (あります) ও বোঝা (わかります) এর বিষয়ের পরে が বসে।

  • 私わたし は 日本語にほんご が わかります。আমি জাপানি বুঝি।
  • 時間じかん が あります。সময় আছে।

💡 あります/わかります এর আগে が।

কোন ধরনের জিনিস পছন্দ তা জিজ্ঞেসে どんな N が বসে।

  • どんな スポーツ が 好すき です か。কী ধরনের খেলা পছন্দ?
  • サッカー が 好すき です。ফুটবল পছন্দ।

💡 どんな + N + が + すき।

よく・だいたい・すこし・あまり・ぜんぜん“পরিমাণ বোঝায়” · 程度の言葉

よく/だいたい/少すこし + 肯定 / あまり/ぜんぜん + 否定

よく = ভালো, だいたい = মোটামুটি, 少[すこ]し = একটু (হ্যাঁ-বোধকের সাথে)।

  • 日本語にほんご が よく わかります。জাপানি ভালো বুঝি।
  • 英語えいご が 少すこし わかります。ইংরেজি একটু বুঝি।

💡 あまり/ぜんぜん এর পরে না-বোধক।

から (কারণ)・どうして“কারণ ও কেন” · から, どうして

S1 から、 S2 / どうして ～ か

S1 から、 S2 = “S1 তাই S2” (কারণ আগে, ফলাফল পরে)।

  • 明日あした テスト です から、 勉強べんきょう します。কাল পরীক্ষা, তাই পড়ব।
  • どうして 日本語にほんご を 勉強べんきょう します か。কেন জাপানি পড়েন?

💡 から = “তাই / কারণ”।

লেসন ১০অস্তিত্ব ও অবস্থান · あります・います

  • 教室きょうしつ に 先生せんせい が います。ক্লাসরুমে শিক্ষক আছেন।

N は 場所 に あります/います

কোনো জিনিস বা মানুষ কোথায় আছে বলতে সেটি は দিয়ে শুরু করা হয় (বিষয়), স্থানের পরে に।

  • 銀行ぎんこう は 駅えき の 前まえ に あります。ব্যাংক স্টেশনের সামনে আছে।
  • ミラー さん は 事務所じむしょ に います。মিলার অফিসে আছেন।

💡 জিনিস は স্থান に ある।

অবস্থানের শব্দ“ওপর, নিচ, ভেতর…” · 上・下・中・前・後ろ・隣

N の 上うえ/下した/中なか/前まえ/後うしろ/隣となり/近ちかく/間あいだ

N + の + অবস্থানের শব্দ, তারপর に।

  • 机つくえ の 上うえ に 本ほん が あります。টেবিলের ওপর বই আছে।

💡 N এবং অবস্থান শব্দের মাঝে の ভুলবেন না।

や ও と“ও / ইত্যাদি” · や, と

N1 や N2 (など) / N1 と N2

と দিয়ে শুধু ঐ দুটোই আছে বোঝায় (সম্পূর্ণ তালিকা)।

  • 机つくえ の 上うえ に 本ほん や ノート が あります。টেবিলের ওপর বই, খাতা ইত্যাদি আছে।
  • 公園こうえん に 犬いぬ や ねこ が います。পার্কে কুকুর, বিড়াল ইত্যাদি আছে।

💡 や = আরও আছে, と = ঐ কটিই।

ありません・いません“নেই” · ありません/いません

N が ありません/いません / だれ も いません

না-বোধক: あります → ありません, います → いません।

  • かばん に 本ほん が ありません。ব্যাগে বই নেই।
  • 教室きょうしつ に だれ も いません。ক্লাসরুমে কেউ নেই।

💡 も এর পরে না-বোধক।

N が ほしい です

কোনো জিনিস চাইলে ほしい বলা হয়।

ক্রিয়ার ます-রূপ থেকে ます বাদ দিয়ে たい যোগ করলে “...করতে চাই” বোঝায়।

N を ください

দোকান বা রেস্টুরেন্টে কিছু চাইতে ください বলা হয়, অর্থ “দয়া করে দিন”।

  • 水みず を ください。পানি দিন।

A は B より 形容詞 です

দুটি জিনিস তুলনা করতে より ব্যবহার হয়।

কোনো দলের মধ্যে সবচেয়ে বেশি কিছু বোঝাতে 一番 বসে।

লেসন ১৩উদ্দেশ্যে যাওয়া ও প্রস্তাব · に行きます・ましょうか

V(ます形の語幹) + に 行きます“...করতে যাই” · に行きます

V(ます形の語幹) + に 行きます / 来ます / 帰ります

কোনো কাজ করার উদ্দেশ্যে কোথাও যাওয়া বোঝাতে ক্রিয়ার ます-স্টেম + に 行きます।

V(ます形の語幹) + ましょうか“আমি কি ...করব?” · ましょうか

V(ます形の語幹) + ましょうか

নিজে কিছু করার প্রস্তাব বা জিজ্ঞাসা করতে ましょうか।

  • 手伝てつだいましょうか。সাহায্য করব কি?
  • はい、 お願ねがいします。হ্যাঁ, অনুগ্রহ করে।

💡 ましょうか = “করব কি?”; ましょう = “চলুন”।

লেসন ১৪অনুরোধ ও ক্রিয়ার て-রূপ · て形・てください

て形 (গঠন)“ক্রিয়ার て-রূপ” · て形

う-ক্রিয়া: く→いて, ぐ→いで, む・ぶ・ぬ→んで, う・つ・る→って, す→して / る-ক্রিয়া: る→て / する→して, 来る→来て

ক্রিয়াকে তিন ভাগে ভাগ করে て-রূপ হয়।

  • 書かいてলিখে (書く)
  • 食たべてখেয়ে (食べる)

💡 শেষ অক্ষর দেখুন: う/つ/る → って, む/ぶ/ぬ → んで, く → いて, ぐ → いで, す → して। ব্যতিক্রম: 行く → 行って।

V-て ください“...করুন” · てください

V-て ください

কাউকে কিছু করার অনুরোধ বা নির্দেশ দিতে てください।

  • ここ に 名前なまえ を 書かいて ください。এখানে নাম লিখে দিন।
  • ゆっくり 話はなして ください。ধীরে ধীরে বলুন।

💡 ください শুধু অনুরোধ; নিষেধে ～ないでください (পরের লেসন)।

লেসন ১৫চলমান কাজ ও থাকা · ～ています

V-て います“করছি / করে আছি” · ています

V-て います

এখন চলছে এমন কাজ বোঝাতে ক্রিয়ার て-রূপ + います।

  • 今いま 本ほん を 読よんで います。এখন বই পড়ছি।
  • 今いま 雨あめ が 降ふって います。এখন বৃষ্টি হচ্ছে।

💡 এখন বোঝাতে 今 বসালে অর্থ স্পষ্ট হয়।

場所 に 住んで います“থাকি” · 住んで います

N に 住んで います

কোথায় থাকেন তা বলতে 住んで います।

  • 私わたし は 東京とうきょう に 住すんで います。আমি টোকিওতে থাকি।
  • 山田やまだ さん は どこ に 住すんで います か。ইয়ামাদা কোথায় থাকেন?

💡 “থাকি” = 住んで います (স্থায়ী বাস)।

লেসন ১৬অনুমতি ও নিষেধ · てもいい・てはいけません

V-て も いい です“...করা যাবে” · てもいい

V-て も いい です / V-て も いい です か

কোনো কাজের অনুমতি চাইতে বা দিতে ～て も いい です।

  • ここ で 写真しゃしん を 撮とって も いい です か。এখানে ছবি তুললে কি ঠিক আছে?
  • はい、 いい です。হ্যাঁ, ঠিক আছে।

💡 “ঠিক আছে” = いい; “না, হবে না” = だめ です।

V-て は いけません“...করা নিষেধ” · てはいけません

V-て は いけません

কোনো কাজ নিষেধ করতে ～て は いけません।

  • ここ で たばこ を 吸すって は いけません。এখানে ধূমপান নিষেধ।
  • 教室きょうしつ で 電話でんわ を して は いけません。ক্লাসে ফোনে কথা বলা নিষেধ।

💡 ては いけません = কড়া নিষেধ; ভদ্রভাবে নিষেধ: ～ないでください।

লেসন ১৭না-রূপ অনুরোধ ও বাধ্যবাধকতা · ないでください・なければなりません

V-ない で ください“...করবেন না” · ないでください

V-ない で ください

ক্রিয়ার ない-রূপ + で ください = ভদ্রভাবে নিষেধ।

  • ここ で 写真しゃしん を 撮とらないで ください。এখানে ছবি তুলবেন না।
  • 遅おそく 来こないで ください。দেরি করে আসবেন না।

💡 “বলবেন না” = 言わないで ください।

V-ない → V-なければ なりません“...করতেই হবে” · なければなりません

V-ない → V-なければ なりません

কোনো কাজ বাধ্যতামূলক হলে ない-রূপের ない বদলে なければ なりません।

  • 明日あした 早はやく 起おきなければ なりません。কাল সকালে আগে উঠতে হবে।
  • 宿題しゅくだい を しなければ なりません。হোমওয়ার্ক করতেই হবে।

💡 “হবেই” = なければなりません; “হবে না” = なくても いい です।

লেসন ১৮সক্ষমতা ও অভিজ্ঞতা · ことができます・たことがあります

V(辞書形) + こと が できます“...করতে পারি” · ことができます

V(辞書形) + こと が できます

কোনো কিছু করার সক্ষমতা বোঝাতে ক্রিয়ার অভিধান রূপ + こと が できます।

  • 私わたし は 日本語にほんご を 話はなす こと が できます。আমি জাপানি বলতে পারি।
  • 車くるま を 運転うんてんする こと が できません。আমি গাড়ি চালাতে পারি না।

💡 できます = পারা; できません = পারি না।

V-た こと が あります“...করেছি (কখনো)” · ことがあります

V-た + こと が あります / V-た + こと が ありません

অভিজ্ঞতা বোঝাতে কখনো কিছু করা হয়েছে কিনা।

  • 日本にほん に 行いった こと が あります。আমি জাপানে গিয়েছি।
  • 寿司すし を 食たべた こと が あります か。সুশি খেয়েছেন কখনো?

💡 “কখনো...করেছি” = ～たことがあります; “কখনো না” = ～たことがありません।

লেসন ১৯কয়েকটি কাজের তালিকা ও পরামর্শ · たり・ほうがいい

V-た り、 V-た り します“কখনো…কখনো…” · たり

V-た り、 V-た り します

কয়েকটি কাজের উদাহরণ দিতে ক্রিয়ার た-রূপ + り ব্যবহার হয়, শেষে します।

  • 休やすみの 日ひ は 映画えいが を 見みたり、 買かい物もの を したり します。ছুটির দিনে সিনেমা দেখি, কেনাকাটাও করি।
  • 週末しゅうまつ は 音楽おんがく を 聞きいたり、 寝ねたり します。সপ্তাহান্তে গান শুনি, ঘুমাই।

💡 “কখনো...কখনো...” = ～たり～たり します।

V-た ほう が いい です“...করা ভালো” · ほうがいい

V-た + ほう が いい です / V-ない + ほう が いい です

কাউকে পরামর্শ দিতে ～た ほう が いい です।

  • 毎日まいにち 運動うんどう した ほう が いい です。প্রতিদিন ব্যায়াম করা ভালো।
  • 夜よる は 遅おそく 寝ねない ほう が いい です。রাতে দেরি করে না ঘুমানো ভালো।

💡 ほうがいい = “ভালো হবে” (পরামর্শ)।

লেসন ২০ক্রম ও আগে-পরে · てから・前に

V-て から、 V“...করার পর” · てから

V-て から、 V

একটি কাজ শেষ করে আরেকটি কাজ বোঝাতে ক্রিয়ার て-রূপ + から।

  • 宿題しゅくだい を して から、 遊あそびます。হোমওয়ার্ক করার পর খেলব।
  • ご飯はん を 食たべて から、 出でかけます。খাওয়ার পর বের হব।

💡 আগে কাজ → て + から।

V(辞書形) 前に / N の 前に“...করার আগে” · 前に

V(辞書形) + 前に / N + の 前に

কোনো কাজের আগে বোঝাতে 前に।

  • 寝ねる 前まえに 歯はを 磨みがきます。ঘুমানোর আগে দাঁত মাজি।
  • 食事しょくじ の 前まえに 手てを 洗あらいます。খাওয়ার আগে হাত ধুই।

💡 前 = আগে; 後 = পরে।

লেসন ২৭পারা ও দেখা-শোনা · 可能形・見えます・しか

V-ます → え段 + ます (Group 1)“-তে পারি” · 可能形 (Group 1)

かきます → かけます

কোনো কাজ করতে পারা বোঝাতে ক্রিয়ার রূপ বদলাতে হয়।

  • 日本語にほんご が 話はなせます。আমি জাপানি ভাষা বলতে পারি।
  • 漢字かんじ が 読よめます。আমি কানজি পড়তে পারি।

💡 い → え¶かき → かけ¶のみ → のめ¶はなし → はなせ

V-ます → V-られます (Group 2)“-তে পারি” · 可能形 (Group 2)

たべます → たべられます

Group 2-এ ます বাদ দিয়ে られます যোগ করতে হয়।

  • 魚さかな が 食たべられます。আমি মাছ খেতে পারি।
  • 朝あさ 早はやく 起おきられます。আমি সকালে তাড়াতাড়ি উঠতে পারি।

💡 ます বাদ + られます

します → できます / きます → こられます“-তে পারি” · 可能形 (Group 3)

します → できます / きます → こられます

Group 3-এ মাত্র দুটি ক্রিয়া আছে।

  • 車くるま が 運転うんてん できます。আমি গাড়ি চালাতে পারি।
  • 明日あした 学校がっこう に 来こられます。আমি আগামীকাল স্কুলে আসতে পারব।

💡 します → できます¶きます → こられます

N が V(可能形)“কী পারি” · を → が

N を V-ます → N が V(可能形)

সাধারণ বাক্যে কাজের কর্মের পরে を বসে।

  • 日本語にほんご を 話はなします。আমি জাপানি ভাষায় কথা বলি।
  • 日本語にほんご が 話はなせます。আমি জাপানি ভাষায় কথা বলতে পারি।

💡 পারা বোঝালে を-এর জায়গায় が।

見えます・聞こえます“দেখা যায় / শোনা যায়” · 見える・聞こえる

N が 見えます / N が 聞こえます

দুটোই আপনা-আপনি হওয়া বোঝায়, ইচ্ছা করে করা নয়।

  • 山やま が 見みえます。পাহাড় দেখা যাচ্ছে।
  • 部屋へや から 海うみ が 見みえます。ঘর থেকে সমুদ্র দেখা যায়।

💡 みます = দেখি¶みえます = দেখা যায়¶ききます = শুনি¶きこえます = শোনা যায়

N が できます“তৈরি হওয়া / পারা” · できます

N が できます

できます এর দুটি অর্থ আছে।

  • 駅えき の 前まえ に スーパー が できました。স্টেশনের সামনে সুপারমার্কেট তৈরি হয়েছে।
  • 晩ばんご飯はん が できました。রাতের খাবার তৈরি হয়ে গেছে।

💡 কিছু বানানো হলে = তৈরি হওয়া¶ভাষা বা কাজ হলে = পারা

N しか V-ません“মাত্র / শুধু” · しか

N しか V-ません (না-বোধক)

しか ব্যবহার করলে ক্রিয়া সবসময় না-বোধক হয়, কিন্তু অর্থ হয় “শুধু এটুকুই, আর কিছু নয়”।

  • ひらがな しか 書かけません。আমি শুধু হিরাগানা লিখতে পারি।
  • 百円ひゃくえん しか ありません。আমার কাছে মাত্র ১০০ ইয়েন আছে।

💡 しか দেখলেই শেষে না-বোধক (ません / ない) খুঁজো।

N は ～が、 N は ～তুলনা · は

N は V が、 N は V-ません

は শুধু বিষয় নয়, দুটি জিনিসের পার্থক্য বোঝাতেও ব্যবহৃত হয়।

  • 日本語にほんご は 話はなせます が、 英語えいご は 話はなせません。জাপানি বলতে পারি, কিন্তু ইংরেজি পারি না।
  • 魚さかな は 食たべられます が、 肉にく は 食たべられません。মাছ খেতে পারি, কিন্তু মাংস পারি না।

💡 দুটি জিনিস মুখোমুখি রাখলে দুটোতেই は।

লেসন ২৮ながら · ています · し · それに · それで

V-ます → ます বাদ + ながら“করতে করতে” · ながら (একই সময়ে দুটি কাজ)

ききます → ききながら

ながら দিয়ে বোঝায় একটি কাজ করার সময়েই আরেকটি কাজ চলছে।

  • 音楽おんがくを 聞ききながら 勉強べんきょうします。গান শুনতে শুনতে পড়াশোনা করি।
  • テレビを 見みながら ご飯はんを 食たべます。টিভি দেখতে দেখতে খাবার খাই।

💡 ききます → きき → ききながら¶たべます → たべ → たべながら¶はなします → はなし → はなしながら¶あるきます → あるき → あるきながら

V(ます) + ています → নিয়মিত অভ্যাস“প্রতিদিন করি / করে থাকি” · ています (অভ্যাস)

まいあさ ジョギングを しています

আগে ています চলমান কাজ বুঝিয়েছে।

  • 毎朝まいあさ ジョギングを しています。আমি প্রতিদিন সকালে জগিং করি।
  • わたしは 毎日まいにち 日本語にほんごを 勉強べんきょうしています。আমি প্রতিদিন জাপানি ভাষা পড়াশোনা করি।

💡 しています → している¶のんでいます → のんでいる¶はたらいています → はたらいている

Verb + し · い-Adj + し · な-Adj / Noun + だし“আর… আবার…” · একাধিক কারণ বা বৈশিষ্ট্য · し

おもしろい → おもしろいし

একাধিক বৈশিষ্ট্য বা কারণ একসঙ্গে বলতে し ব্যবহার হয়।

  • 日本語にほんごは おもしろいし、便利べんりです。জাপানি ভাষা মজার, আর উপকারীও।
  • この部屋へやは 明あかるいし、広ひろいです。এই ঘরটি উজ্জ্বল এবং বড়ও।

💡 いくし (Verb)¶やすいし (い-Adj)¶しずかだし (な-Adj)¶せんせいだし (Noun)

それに“তাছাড়া / তার ওপর” · それに (নতুন তথ্য যোগ)

やすいです。それに、きれいです。

আগের কথার সঙ্গে নতুন একটি তথ্য যোগ করতে それに বসে।

  • この ホテルは 安やすいです。それに、きれいです。এই হোটেলটি সস্তা। তাছাড়া সুন্দরও।
